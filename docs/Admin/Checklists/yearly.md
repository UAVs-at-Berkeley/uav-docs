# Annual Todos

Stuff that should be done every fall at the beginning of the semester:

- Submit a project proposal to the [Mechanical Engineering Student Access Machine Shop](https://me.berkeley.edu/resources/student-machine-shop/) to be eligible for club shop training slots and access to their services.
  Leads should receive an email soliciting project proposals. See a past example [here](/assets/meshop_proposal_example.pdf).
- Apply for [discounted club maker passes](https://jacobsinstitute.berkeley.edu/for-student-groups/) at the [Jacobs Institute](https://jacobsinstitute.berkeley.edu).
- Update the sponsor packet.ex
